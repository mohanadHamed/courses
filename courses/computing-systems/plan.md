# Fundamentals of Computing Systems and Digital Platforms (13411133) — 16-week plan

Status: draft for approval, 2026-10-19. Source: official syllabus (2026-2027, Drive) and the ILO–PLO matrix v4.
The weekly map below is a copy of `schedule.yml` (titles and ILOs from the syllabus); if they differ, `schedule.yml` wins.

Per week (as taught): 2 × 60 min → 2 lessons (A = Lecture, B = Seminar). Each lesson has notes (PDF), an interactive page and slides (see AUTHORING.md).

## Course ILOs

| Code | ILO (official text, with PLOs) |
|---|---|
| A1 | Describe the components of computers and smartphones and the function of each. (PLO 1) |
| A2 | Explain the functions of operating systems and the concepts of networking and cloud computing. (PLO 1) |
| B1 | Compare mobile platforms (Android and iOS) and gaming platforms in terms of capabilities and limitations. (PLO 1, 3) |
| B2 | Analyze the impact of device and platform specifications on game performance and compatibility. (PLO 1, 4) |
| C1 | Set up testing environments for games using emulators and real devices. (PLO 1, 3) |
| C2 | Describe the requirements for publishing games on app stores and cloud services. (PLO 3, 4) |
| D1 | Use reliable sources for self-learning and follow developments in digital platforms. (PLO 3) |

## Notes

- **Independent study, no group work.** The syllabus seminar "Platform comparison activity" (week 9) becomes an individual analysis with reliable sources (D1), and the week-15 student presentations become an individual project report on performance and compatibility, with an optional short recorded presentation.
- D1 (reliable sources, self-learning) is an individual competence by nature: practise it in weeks 9 and 15 with source lists and short source evaluations.
- Week 8: midterm exam and midterm discussion (no lessons). Week 16: final exam.
- One homework per week; week 15: the project instead (syllabus).
