Folders, paths and good file names.
In this video, we put Sara's course files in order.

A file is one saved piece of work, like a CV.
A folder keeps files and other folders.
Folders inside folders make a tree.
Sara has one folder for each course and each unit.

The path is the full address of a file.
It starts with the drive.
Then it goes down the tree, one folder at a time.
Look at the path of Sara's CV.
Two files can have the same name, but never the same path.

The end of the name, after the dot, is the extension.
It shows the type of file, and the app that opens it.
Here you see three extensions: Word, Excel and PowerPoint.

Good file names follow four rules.
One: the name says what is in the file.
Two: no spaces. Use a dash or an underscore.
Three: write the date as year, month and day.
Then your files sort by date.
Four: add a version number, and never the word final.

Look at this bad name for a CV.
The good name has the date, what it is, and the version.
Now the file is easy to find, and easy to sort.
